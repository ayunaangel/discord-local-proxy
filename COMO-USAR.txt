====================================================================
 DISCORD PROXY — como usar
====================================================================

PARA QUE SERVE
--------------
Faz o Discord sair para a internet por outro país. Isso muda a região
do servidor da chamada, que é o mesmo por onde passam a CÂMERA e o
COMPARTILHAMENTO DE TELA. Serve para quando esses recursos ficam
indisponíveis por causa da sua região.

Só o Discord é afetado. O resto do computador continua normal.


COMO ABRIR
----------
Windows: clique duas vezes em INICIAR-WINDOWS.cmd
Linux:   clique duas vezes em INICIAR-LINUX.sh e escolha "Executar"


O WINDOWS BLOQUEOU / O ANTIVÍRUS ACUSOU
---------------------------------------
Isso é falso positivo, e acontece porque o programa não tem assinatura
digital — o certificado para assinar é pago e este projeto não tem. O
Windows desconfia de qualquer programa novo e desconhecido, mesmo que
ele não faça nada de errado.

Você tem três saídas. A primeira é a mais simples e nem mexe no
antivírus:

1) RODAR PELO CÓDIGO-FONTE (o caminho recomendado se você foi bloqueado)
   Quem passa a rodar é o Python, que é um programa assinado e conhecido.
   - Instale o Python: https://www.python.org/downloads/
     Na instalação, MARQUE a caixa "Add Python to PATH".
   - Baixe o código em https://github.com/ayunaangel/discord-local-proxy
     (botão verde "Code" > "Download ZIP"), extraia e clique duas vezes
     em INICIAR-WINDOWS.cmd.

2) CONFERIR E LIBERAR O ARQUIVO
   Na página de releases, cada pacote tem um arquivo .sha256 ao lado.
   Abra o Prompt de Comando na pasta onde você baixou e rode:

       certutil -hashfile DiscordProxy-Windows-x64.zip SHA256

   Se o código que aparecer for igual ao que está no arquivo .sha256, o
   pacote é exatamente o que o GitHub gerou a partir do código público.
   Aí dá para liberar:
   - Abra "Segurança do Windows"
   - "Proteção contra vírus e ameaças" > "Histórico de proteção"
   - Ache o item, clique em "Ações" e escolha "Permitir no dispositivo"
   - Se precisar, em "Gerenciar configurações" > "Exclusões", adicione a
     pasta do programa.

3) AVISAR A MICROSOFT DO ERRO
   Em https://www.microsoft.com/en-us/wdsi/filesubmission dá para enviar
   o arquivo como falso positivo. Costuma sair em alguns dias e conserta
   para todo mundo, não só para você.

NÃO DESLIGUE O ANTIVÍRUS. Liberar um arquivo depois de conferir o hash
dele é uma coisa; ficar sem proteção é outra bem diferente.

Se a acusação falar de um arquivo chamado "version.dll": esse é o ajuste
de voz, que serve só para rede que bloqueia chamada e vem DESLIGADO. Ele
fica guardado dentro da pasta do programa e não encosta na pasta do
Discord enquanto você não ligar a opção de voz nos ajustes avançados.


PASSO A PASSO
-------------
1. Na janela, escolha em "De onde você quer sair":

      Daqui mesmo        = sem trocar nada
      Tor · Automático   = o programa liga o Tor sozinho
      Tor · Holanda      = (ou outro país da lista)
      Meu próprio proxy  = se você tem uma VPS

2. FECHE O DISCORD POR INTEIRO. Isso inclui o ícone que fica ao lado
   do relógio: clique com o botão direito nele e escolha sair.
   Se o Discord já estiver aberto, ele ignora a troca.

3. Clique em "Abrir o Discord".

4. DEIXE A JANELA DO DISCORD PROXY ABERTA enquanto estiver usando.
   Se fechar, o Discord volta a sair pela sua conexão normal.

5. Para conferir se funcionou, clique em "Onde estou saindo".
   Depois, dentro de uma chamada, clique em "Região da chamada".


PARA USAR O TOR
---------------
Instale o Tor Browser: https://www.torproject.org/pt-BR/download/
Depois de instalar, deixe a pasta em Downloads. O programa acha
sozinho. Você NÃO precisa abrir o Tor Browser — o programa usa só a
parte de rede dele, sem abrir janela nenhuma.

AVISO IMPORTANTE SOBRE O TOR: ele é lento para enviar arquivos. Se
você mandar uma imagem no Discord e ela sumir, é por isso. O Tor
serve bem para conversar e para testar se a troca de região resolve
o seu caso; para trabalhar o dia todo, use um proxy próprio.


SE ALGO TRAVAR
--------------
Clique em "Encerrar sessão" na janela. Isso fecha o Discord e desliga a
saída — depois é só abrir o Discord normalmente.

Pelo terminal, o mesmo:

    INICIAR-LINUX.sh parar        (ou INICIAR-WINDOWS.cmd parar)

Enquanto você usa, se alguma conexão passar de 25 segundos, a janela
avisa que a saída está lenta. É o sinal de que enviar imagem vai falhar.


QUANDO ALGO DER ERRADO
----------------------
Clique em "Salvar relatório (.txt)". O arquivo vai para a sua Área de
Trabalho com o nome discord-proxy-relatorio.txt. Mande esse arquivo
para quem for te ajudar.

O relatório NÃO contém sua senha nem suas conversas.


PROBLEMAS COMUNS
----------------
"O Discord já está aberto"
    Feche pelo ícone ao lado do relógio, não só a janela.

"Tor não encontrado"
    Instale o Tor Browser e deixe a pasta em Downloads. Ou informe a
    pasta em "Ajustes avançados".

"O Tor não conseguiu abrir um circuito"
    Se você escolheu um país, tente "Automático" — pode não haver
    servidor disponível naquele país no momento.

A imagem some quando eu envio
    O Tor é lento para enviar. Se a janela avisou que a saída está
    lenta, é isso. Use um proxy próprio, ou clique em "Encerrar
    sessão" para voltar ao normal enquanto precisar mandar arquivos.

O Discord não foi encontrado
    Em "Ajustes avançados", informe o caminho do programa.

"O Windows protegeu o seu computador", ou o antivírus apagou o arquivo
    Falso positivo. Veja "O WINDOWS BLOQUEOU" no começo deste arquivo.
